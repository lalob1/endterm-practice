# Endterm Practice

A Big Data Analytics practice quiz with 47 multiple-choice questions from four sample sets. The quiz opens on All questions. Pick a set to see its original question numbers. Wrong answers show an explanation and can be retried immediately. Your progress stays in the browser.

Open `docs/index.html` to practice offline. To regenerate the static site after editing the question banks or interface, run `node build.mjs docs`. The build uses Node.js with no npm dependencies. The prepared GitHub Pages source is `main`, `/docs`.
